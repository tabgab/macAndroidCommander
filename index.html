Troubleshooting:

  1. Enable Developer Options: Go to Settings > About Phone > Tap "Build Number" 7 times.
  2. Enable USB Debugging: Go to Settings > System > Developer Options > Enable "USB Debugging".
  3. Authorize Computer: Check your phone screen for a prompt to allow USB debugging from this computer.
  4. Check Cable: Ensure you are using a data-capable USB cable.
